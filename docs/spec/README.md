# Behaviour spec (clean room)

This folder describes what XML Atlas should do, in our own words. It is written from using
XML Marker and the Qt XML Atlas, and from the XML specification. It never includes copied text,
screenshots or assets from XML Marker.

One file per area. Each states the behaviour, edge cases and an acceptance test.

| File (to write)      | Area                                                        |
|----------------------|-------------------------------------------------------------|
| `open.md`            | Opening files, encodings, malformed input, very large files |
| `tree.md`            | Tree contents, expansion, selection, keyboard               |
| `grid.md`            | Which rows and columns appear, editing cells, sorting       |
| `text.md`            | Source view, sync with tree and grid, editing               |
| `format.md`          | Indentation rules, what whitespace is kept                  |
